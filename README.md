# AI Coach — Android MVP 0.1

This is the first native Android project scaffold for the AI Coach.

## Current scope
- Home dashboard
- AI Coach conversation UI
- Training screen
- Nutrition placeholder
- Health placeholder
- Profile placeholder
- Android-native Jetpack Compose structure

## Next integrations
1. Real AI backend and authenticated user profile
2. Persistent database
3. Health Connect permissions and data ingestion
4. Xiaomi/Mi Fitness → Health Connect testing
5. Camera + meal vision
6. Equipment recognition
7. Neural voice
8. Recovery/personalization engine
9. Security hardening and production release

## Build
Open this project in a compatible Android development/cloud environment and run the `app` configuration.

This repository is intentionally a scaffold: it does not contain API keys, production health permissions, or a real AI endpoint.
